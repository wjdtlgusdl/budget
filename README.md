# 예산서 검토 앱 v27

v26 기반 개선본입니다.

## 변경 사항
- 결과표를 `구분 / 항목 / 엑셀금액 / 엑셀인원 / PDF금액 / PDF인원 / 검토결과` 형식으로 정리했습니다.
- PDF 인원은 같은 산출항목이 보조금/수익자부담금으로 나뉜 경우 중복 합산하지 않도록 보정했습니다.
- 급여 차액이 다른 목에 편성된 경우 검토결과에 차액 원인을 함께 표시합니다.
- 수당은 엑셀 항목별로 표시하고, PDF 개별 편성이 없으면 PDF금액 0원/0명으로 표시한 뒤 통합편성 산식을 검토결과에 표시합니다.
- `식대 ↔ 정액급식비` 처리는 교원/직원 수당 목 범위에서만 적용합니다.
