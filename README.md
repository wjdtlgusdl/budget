# 예산서 검토 웹앱 v38

v37 기반 수정본입니다.

## v38 변경사항
- 퇴직금/퇴직적립금은 엑셀과 PDF의 금액 일치 여부를 검토하지 않습니다.
- 엑셀 퇴직 관련 시트에 실제 적립금액이 있으면 PDF에 퇴직 관련 목/산출항목이 편성되어 있는지만 확인합니다.
- 0원, 빈값, 수식오류는 퇴직 적립금액 없음으로 처리합니다.
- PDF의 `퇴직금`, `퇴직적립금`, `퇴직금및퇴직적립금`은 같은 계열로 인식합니다.

Cloudflare Pages 배포 시 Build output directory는 `public`입니다.

## v41 변경사항
- v38 안정 버전을 기준으로 수정했습니다.
- 인원 차이는 검토 대상에서 제외하여 결과표에 엑셀인원/PDF인원을 표시하지 않습니다.
- 인건비성 산출기초에서 `인원 수` 또는 `월수`가 빠진 경우 지적사항으로 표시합니다.
- 퇴직적립금 판정 기준은 v38 그대로 유지했습니다.

## v42 변경사항
- 보수일람표 사용범위가 A1:XFB처럼 과도하게 넓게 저장된 파일에서도 실제 값이 있는 열까지만 탐색합니다.
- `기본급`을 `본봉`과 동일한 급여 기준 열로 처리합니다.
- 퇴직 적립 여부는 퇴직 관련 시트의 `적립금이월액` 구역 `계` 금액 기준으로 판단합니다.


## v43 변경사항
- PDF 산출내역 앞의 [방], [급], [운영] 같은 태그를 제거하고 같은 수당명으로 합산합니다.
- 산출내역과 산출기초가 같은 줄에 있는 경우도 항목명을 직접 추출합니다.
- 괄호/중괄호 산식 예: (원장500,000원+부원장200,000원+교사50,000원)*12월 형태를 금액 편성으로 인식합니다.


## v46
- v45의 과도한 PDF 수당 매칭을 되돌리고 v43 안정 파서를 기준으로 재구성했습니다.
- [방]/[급]/[운영] 태그 수당 합산은 유지합니다.
- 괄호 산식 수당 인식과 일반 상여금 매칭을 보강했습니다.


## v49
- PDF 산출내역 블록 전체 기준 수당 매칭 보강
- [방]/[급] 등 접두 수당 합산 안정화
- 직원급여 차액이 통학차량이용비 목 합계와 일치하는 경우 오편성 설명 추가

## v50 보강 내용

- 1번 파일(예산서 작성서식)에 `.xlsx/.xls`뿐 아니라 텍스트형 `.pdf`도 업로드할 수 있도록 입력 허용 범위를 확장했습니다.
- 엑셀 시트명뿐 아니라 시트 내부의 `직명`, `본봉/기본급`, `지급액계`, `소계(교원)`, `소계(직원)` 등 내용 기반으로 보수표 후보를 찾도록 보강했습니다.
- 퇴직금 검토에서 가능한 경우 교원/직원 구분을 함께 확인하도록 보조 로직을 추가했습니다.
- 수식 셀에 저장 계산값이 없을 때 `SUM(A1:B2)` 및 단순 사칙연산 수식을 제한적으로 계산하도록 보정했습니다.
- 작성서식 PDF가 스캔본인 경우 정확한 인식이 어렵다는 안내 문구를 추가했습니다.
- 금액 차이가 다른 목에서 발견되는 경우 지적사항 문구를 `○○원 금액을 정상 목이 아닌 다른 목에 편성` 형태로 정리했습니다.

※ 작성서식 PDF는 엑셀에서 변환된 텍스트형 PDF만 1차 지원합니다. 이미지 스캔 PDF는 브라우저 정적 웹페이지 구조상 OCR 없이 안정적으로 인식하기 어렵습니다.


## v53 변경사항
- 특정 기관/직종 하드코딩을 줄이고 금액+항목명 토큰+목 구조 기반의 범용 오편성 탐색으로 보강했습니다.
- [방]/[급]/[운영] 등 접두어가 붙은 동일 수당을 핵심 수당명 기준으로 합산 매칭합니다.
- 산출내역과 산출기초가 여러 줄이거나 복잡 산식인 경우, 첫 번째 완성 산식 단위로 블록을 잘라 오매칭을 줄였습니다.
- 같은 금액 후보가 여러 개일 때 단순 금액 일치보다 항목명 유사도가 높은 후보를 우선합니다.
