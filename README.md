# 예산서 검토 앱 v23

v22의 PDF 목 기준 파싱을 유지하면서 수당 명칭 정규화를 보강한 버전입니다.

## 변경사항
- `교원성과상여금` ↔ `성과상여금`처럼 교원/직원 접두어가 붙어도 같은 항목으로 매칭합니다.
- `식대` ↔ `정액급식비` ↔ `급식비`를 같은 항목으로 봅니다.
- PDF 산출항목명이 목명으로 뭉개지는 경우에도, 같은 `교원수당/직원수당` 목 안에서 금액이 일치하면 편성된 것으로 판단합니다.
- 법정부담금 제외, 퇴직적립금 0원 제외, 인건비 오편성 동적 탐지는 유지합니다.


## v24 변경사항
- 식대/정액급식비 동의어 매칭은 교원수당·직원수당 목 내부에서만 적용합니다.
- 일반급식비, 특별급식비, 식재료비, 교직원식재료비는 식대와 별도 항목으로 처리합니다.
