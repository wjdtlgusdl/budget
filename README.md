# 예산서 검토 앱 - 파싱 디버그 버전 v17

이 버전은 최종 검토 판정을 내리기 전, 엑셀과 PDF에서 값이 제대로 추출되는지 확인하기 위한 점검용입니다.

## Cloudflare Pages

- Framework preset: None
- Build command: 비움
- Build output directory: `public`

## 사용법

1. 엑셀 예산서와 PDF 세출예산명세서를 업로드합니다.
2. `값 추출하기`를 누릅니다.
3. 아래 항목을 확인합니다.
   - 선택된 보수 시트
   - 직명/본봉/지급액계 열 위치
   - 교원/직원 본봉 및 인원
   - 수당별 추출 금액
   - 퇴직 관련 시트의 양수 금액 존재 여부
   - PDF 항목별 금액/인원/산출기초
4. 결과가 이상하면 `JSON 다운로드` 파일을 기준으로 파서 규칙을 보정합니다.

## 주의

이 버전은 최종 지적사항을 확정하는 버전이 아니라, 값 인식 정확도를 확인하는 버전입니다.
