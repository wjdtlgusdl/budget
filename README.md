# 예산서 검토 앱 v26

v25 기반 수정본입니다.

## 주요 변경
- PDF 인원은 `목` 기준 산출기초의 인원을 합산합니다.
  - 예: 교원급여 목 안의 교원급여 + 방과후교원급여 인원 합산
- 금액/인원 검토의 확인 문구를 구체화했습니다.
  - 차액, 부족/초과 인원, 다른 목 편성 원인 표시
- 수당을 `교원수당/직원수당` 하나로만 표시하지 않고 엑셀 수당 항목별로 표시합니다.
- PDF 개별 항목이 없지만 미개별 수당 합계가 PDF 교원수당/직원수당 재원별 금액과 일치하면 통합편성으로 표시합니다.
- PDF 천원 단위 편성에 따른 ±1,000원 오차를 허용합니다.
