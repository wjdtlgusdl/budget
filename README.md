# 예산서 검토 웹앱 v38

v37 기반 수정본입니다.

## v38 변경사항
- 퇴직금/퇴직적립금은 엑셀과 PDF의 금액 일치 여부를 검토하지 않습니다.
- 엑셀 퇴직 관련 시트에 실제 적립금액이 있으면 PDF에 퇴직 관련 목/산출항목이 편성되어 있는지만 확인합니다.
- 0원, 빈값, 수식오류는 퇴직 적립금액 없음으로 처리합니다.
- PDF의 `퇴직금`, `퇴직적립금`, `퇴직금및퇴직적립금`은 같은 계열로 인식합니다.

Cloudflare Pages 배포 시 Build output directory는 `public`입니다.


## v39
- 보수일람표 헤더 탐색 실패 시 소계(교원)/소계(직원) 행의 숫자 구조로 본봉/지급액계 열을 추론합니다.
- 해아뜰 등 스타일 호환 문제가 있는 XLSX에서 보수표 인식 안정성을 보강했습니다.


## v40
- 값 추출 단계별 진행 표시 추가
- 퇴직 적립 판단 기준을 퇴직 관련 시트의 `기적립현황` 구역 `소계` 열 양수 금액으로 변경
- 퇴직금은 계속 금액 일치 비교 제외, 편성 여부만 확인
