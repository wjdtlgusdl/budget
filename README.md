# 인건비 예산 대조 도구

교직원보수일람표가 들어 있는 예산서 엑셀 파일과 세출예산명세서 파일을 업로드해 다음 항목을 점검하는 정적 웹앱입니다.

- 교원/직원 인건비 구분 검토
- 급여·수당 항목별 편성 여부 검토
- 편성되어 있으나 금액 차이가 있는 경우 차액 표시
- 연구수당, 시간외수당, 직급보조비 등 수당이 개별 편성되지 않고 `교원수당`, `직원수당`처럼 통합 편성된 경우 지적
- 퇴직적립금/퇴직금적립 관련 시트에 금액이 있으나 세출예산명세서에 대응 내역이 없는 경우 표시
- 결과 엑셀 다운로드

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. 예산서 엑셀 파일을 업로드합니다.
3. 세출예산명세서 PDF, 엑셀, CSV, TXT 파일을 업로드합니다.
4. 필요하면 키워드를 기관 양식에 맞게 수정합니다.
5. `대조 실행`을 누릅니다.
6. 결과표에서 문제 항목을 확인하고 `결과 엑셀 다운로드`를 누릅니다.

## GitHub 업로드 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 그대로 업로드합니다.
3. `Settings > Pages`에서 배포하거나, Cloudflare Pages에 연결합니다.

## Cloudflare Pages 배포 방법

1. Cloudflare Dashboard > Workers & Pages > Pages > Connect to Git
2. GitHub 저장소 선택
3. Framework preset: `None`
4. Build command: 비워둠
5. Build output directory: `/`
6. Deploy

## 개인정보/보안

파일 분석은 브라우저 내부에서만 수행됩니다. 별도 서버로 파일을 업로드하지 않습니다.
단, 라이브러리는 CDN에서 불러옵니다. 완전한 내부망 사용이 필요하면 `xlsx`와 `pdfjs` 파일을 다운로드해 로컬 파일로 교체하세요.

## 주의사항

PDF는 표 구조가 깨질 수 있으므로, 가능하면 세출예산명세서도 엑셀 또는 CSV 형태가 가장 정확합니다. PDF 사용 시에는 텍스트 추출 결과에 따라 일부 항목이 누락될 수 있습니다.
