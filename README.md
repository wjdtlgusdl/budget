# 예산서 검토 정적 웹앱 v7

GitHub Pages 또는 Cloudflare Pages에 그대로 업로드해 사용할 수 있는 정적 웹앱입니다.

## v7 핵심 변경사항

- 엑셀 검토 대상 시트를 **보수기준/교직원보수일람표 시트**와 **퇴직 관련 시트**로 제한했습니다.
- `월급여`, `비월정수당` 등 다른 시트는 사용하지 않습니다.
- 보수기준 시트 파싱 규칙:
  - `직명` 헤더 아래부터 `소계(교원)` 전까지: 교원
  - `소계(교원)` 다음부터 `소계(직원)` 또는 `소계(일반직)` 전까지: 직원
  - `본봉` 또는 `기본급` 열: 급여 기준액
  - 본봉/기본급 바로 다음 열부터 `지급액계` 바로 전 열까지: 수당
- 법정부담금, 4대보험, 사학연금 등은 검토 제외합니다.
- 퇴직 관련 시트는 이름에 `퇴직`이 들어간 시트를 찾아 편성 여부만 확인합니다.

## 검토 항목

1. 교원급여 금액 및 인원수
2. 방과후교원급여 금액 및 인원수
3. 직원급여 금액
4. 수당 개별편성/통합편성/추가확인
5. 퇴직적립금 편성 여부
6. 인건비성 항목의 비인건비 과목 오편성

## 배포

저장소 루트에 파일을 업로드한 뒤 GitHub Pages 또는 Cloudflare Pages에서 정적 사이트로 배포하면 됩니다.

## v8 변경사항
- 대상 시트를 찾지 못해도 `!ref` 오류로 중단되지 않도록 방어 코드를 추가했습니다.
- 보수기준/교직원보수일람표 시트 탐색 실패 시 인식된 시트 목록을 오류 메시지에 표시합니다.
- `월급여`, `비월정수당` 등 기타 시트는 계속 제외하고 보수기준/퇴직 관련 시트만 활용합니다.


## v9 변경사항
- 보수기준 시트명이 정확히 일치하지 않아도 인식합니다.
- 숨겨진 시트는 제외합니다.
- 보이는 시트 중 이름 또는 내용에 `보수`, `급여`, `봉급`, `인건비`, `교직원` 등이 포함되고 실제 보수표 헤더가 있는 시트를 우선 선택합니다.
