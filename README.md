# 예산 인건비 대조 도구 v5

교직원보수일람표와 세출예산명세서를 비교하는 정적 웹사이트입니다. GitHub Pages 또는 Cloudflare Pages에 그대로 배포할 수 있습니다.

## v5 변경사항

- 세출예산명세서의 전체 인건비 합계가 아니라 `인건비 > 교원인건비/직원인건비 > 해당 목` 기준으로 비교합니다.
- 예: 교원급여는 `인건비-교원인건비-교원급여` 목 합계와 비교합니다.
- PDF 텍스트를 줄 단위로 복원하고, `관 > 항 > 목` 구조를 먼저 파싱한 뒤 해당 목 안의 산출기초만 비교합니다.
- 목 합계와 산출기초 합계를 별도로 표시합니다.
- 교원급여/직원급여 같은 목 자체 비교는 목 합계를 기준으로 하며, 산출기초 합계도 함께 검증용으로 표시합니다.
- 교원수당/직원수당 안의 시간외근무수당, 교통보조비, 식대보조비, 명절휴가비 등은 상위 항 합계가 아니라 해당 산출기초 금액만 잡습니다.
- 결과표에 다음 금액을 분리 표시합니다.
  - 예산서금액
  - 명세서목합계
  - 산출기초합계
  - 비교명세서금액
  - 차액
- 퇴직적립금은 금액 일치 여부를 비교하지 않고, 세출명세서에 퇴직적립금 항목이 아예 없는 경우만 지적합니다.

## 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Cloudflare Pages에서 저장소를 연결합니다.
3. 설정값:
   - Framework preset: None
   - Build command: 비움
   - Output directory: `/`

## 사용법

1. 예산서 엑셀 파일을 업로드합니다.
2. 세출예산명세서 PDF 또는 엑셀/CSV 파일을 업로드합니다.
3. 대조 실행을 누릅니다.
4. 결과를 화면에서 확인하거나 엑셀로 다운로드합니다.
