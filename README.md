# 예산서 검토 웹앱 v38

v37 기반 수정본입니다.

## v38 변경사항
- 퇴직금/퇴직적립금은 엑셀과 PDF의 금액 일치 여부를 검토하지 않습니다.
- 엑셀 퇴직 관련 시트에 실제 적립금액이 있으면 PDF에 퇴직 관련 목/산출항목이 편성되어 있는지만 확인합니다.
- 0원, 빈값, 수식오류는 퇴직 적립금액 없음으로 처리합니다.
- PDF의 `퇴직금`, `퇴직적립금`, `퇴직금및퇴직적립금`은 같은 계열로 인식합니다.

Cloudflare Pages 배포 시 Build output directory는 `public`입니다.

## v41 변경사항
- v38 안정 버전을 기준으로 수정했습니다.
- 인원 차이는 검토 대상에서 제외하여 결과표에 엑셀인원/PDF인원을 표시하지 않습니다.
- 인건비성 산출기초에서 `인원 수` 또는 `월수`가 빠진 경우 지적사항으로 표시합니다.
- 퇴직적립금 판정 기준은 v38 그대로 유지했습니다.
