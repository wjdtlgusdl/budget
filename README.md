# 예산서 검토 정적 웹앱

교직원 보수기준 엑셀 파일과 세출예산명세서 PDF 파일을 브라우저에서 비교 검토하는 정적 웹앱입니다.

## 주요 기능

- 엑셀 교직원보수기준 시트 자동 탐색
- PDF 세출예산명세서 산출기초 자동 추출
- PDF 천원 단위 금액과 엑셀 원 단위 금액 비교
- 교원급여 인원수 비교
- 방과후교원급여, 직원급여 등 주요 인건비 비교
- 수당 개별 편성 확인
- PDF에 없는 수당 합계를 교원수당/직원수당 통합편성으로 판단
- 퇴직금 관련 시트에 적립금액이 있을 경우 PDF 편성 여부 확인
- 인건비성 항목이 급식비, 통학차량비 등 비인건비 과목에 편성된 경우 오편성 의심 표시

## GitHub 업로드 방법

1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다.
2. Cloudflare Pages에서 해당 GitHub 저장소를 연결합니다.
3. Framework preset은 `None` 또는 `Static HTML`로 선택합니다.
4. Build command는 비워둡니다.
5. Build output directory는 `/` 또는 비워둡니다.

## 사용 방법

1. 웹페이지에서 엑셀 파일을 업로드합니다.
2. 세출예산명세서 PDF 파일을 업로드합니다.
3. `검토 시작`을 누릅니다.
4. 결과 표에서 정상, 통합편성, 추가확인, 지적 항목을 확인합니다.

## 주의사항

- 모든 처리는 브라우저 내부에서 이루어집니다.
- 파일은 서버로 전송되지 않습니다.
- 엑셀 양식이 기관마다 다를 수 있으므로 실제 배포 전 예시 파일 여러 개로 검증해야 합니다.
- 자동 판정 결과는 최종 회계 검토를 대체하지 않으며, 보조 검토 도구로 사용해야 합니다.

## 커스터마이징 위치

`app.js` 상단의 `RULES` 객체에서 다음 항목을 수정할 수 있습니다.

- 보수 시트 탐색 키워드
- 퇴직금 시트 탐색 키워드
- 교원/직원/방과후 인원 분류 키워드
- 수당 헤더 키워드
- PDF 예산 항목 별칭
- 인건비 오편성 탐지 키워드
