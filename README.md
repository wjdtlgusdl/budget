# 세출예산명세서 검토 정적웹앱

GitHub + Cloudflare Pages에 바로 올릴 수 있는 무료 공개용 정적웹앱입니다. 서버 없이 브라우저에서만 엑셀 예산서와 PDF 세출예산명세서를 분석합니다.

## 주요 기능

- 엑셀 공개 시트만 분석
  - 숨김 시트와 매우 숨김 시트는 제외합니다.
- 보수 일람표와 세출예산명세서 비교
  - 본봉/기본급, 시간외수당, 연구활동비, 식대, 명절휴가비, 방학휴가비, 성과상여금 등 기본 항목을 탐지합니다.
- PDF 천원 단위 처리
  - PDF 금액이 천원 단위로 보이면 원 단위로 환산해 비교합니다.
- 산출기초 분할 표기
  - 동일 항목의 산출기초가 여러 줄로 나뉘고 합계가 맞으면 `분리 편성 되어 있음`으로 표시합니다.
- 퇴직금 편성 여부 확인
  - 엑셀 공개 시트에 퇴직금/퇴직적립금 금액이 있으면 PDF에 관련 예산이 편성되어 있는지만 확인합니다.
  - 퇴직금은 금액 비교를 하지 않습니다.
- PDF 전체 검색
  - 예상 목에서 못 찾으면 PDF 전체를 검색합니다.
  - 예: 영양사 인건비가 직원인건비가 아니라 급식비에 있으면 `급식비에 편성`으로 표시합니다.
- 통합 편성 의심 표시
  - 수당이 개별 항목이 아니라 `교원수당`, `직원수당`, `제수당` 등으로 묶인 경우 확인 필요로 표시합니다.
- 결과 다운로드
  - CSV, JSON 다운로드를 지원합니다.

## 로컬 실행

정적 파일이라 별도 빌드가 필요 없습니다. 다만 브라우저 보안 정책 때문에 로컬 서버로 여는 것을 권장합니다.

```bash
python3 -m http.server 5173
```

브라우저에서 아래 주소를 엽니다.

```text
http://localhost:5173
```

## Cloudflare Pages 배포

1. Cloudflare Dashboard 접속
2. Workers & Pages → Create application → Pages 선택
3. GitHub 저장소 연결
4. Build command: 비워둠
5. Build output directory: `/` 또는 비워둠
6. 배포

## 판정 기준 요약

| 구분 | 처리 방식 |
|---|---|
| 숨겨진 시트 | 분석 제외 |
| PDF 천원 단위 | 원 단위로 환산 후 비교 |
| 본봉/기본급 | 금액 비교 |
| 수당 | 개별 비교, 단 통합 편성 의심 표시 |
| 퇴직금 | 금액 비교 안 함, 편성 여부만 확인 |
| 예상 목 미발견 | PDF 전체 검색 |
| 산출기초 여러 줄 | 합계와 인원수가 맞으면 `분리 편성 되어 있음` |

## 주의사항

이 앱은 공개용 정적웹앱의 초기 버전입니다. PDF의 표 구조가 기관별로 크게 다르면 텍스트 추출 결과가 달라질 수 있습니다. 정확도를 높이려면 `app.js`의 `CONFIG` 영역에 기관별 항목명, 목명, 동의어를 추가하세요.

민감한 개인정보가 포함된 예산서는 공개 저장소에 샘플 파일로 올리지 않는 것을 권장합니다. 이 프로젝트에는 업로드된 원본 예산서와 PDF 파일을 포함하지 않았습니다.
