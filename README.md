# 예산서 자동 검토 도구

교직원 보수 일람표 엑셀 파일과 세출예산명세서 PDF를 비교해 예산 편성 적정성을 점검하는 공개용 정적 웹앱입니다.

## 주요 기능

- 엑셀 보수 항목과 PDF 세출예산명세서 금액 비교
- PDF 천원 단위 금액을 원 단위로 환산하여 비교
- 불일치 시 차이 금액 표시
- 과소편성 / 과다편성 / 미편성 / 적정 판정
- 수당 통합 편성 의심 표시
- 퇴직적립금 시트에 적립금액이 있으면 PDF 편성 여부만 확인
- 인건비 목에 없으면 PDF 전체에서 타 목 편성 여부 탐색
- 결과 CSV 다운로드
- 파일을 서버로 전송하지 않고 브라우저에서 처리

## 사용 방법

1. 이 저장소를 GitHub에 업로드합니다.
2. GitHub Pages 또는 Cloudflare Pages에 배포합니다.
3. 웹페이지에서 엑셀 파일과 PDF 파일을 선택합니다.
4. `검토 시작`을 누릅니다.
5. 결과표를 확인하거나 CSV로 다운로드합니다.

## Cloudflare Pages 배포

- Framework preset: `None`
- Build command: 비워둠
- Build output directory: `/`

## 보안 원칙

현재 버전은 정적 웹앱으로, 파일은 사용자의 브라우저 안에서만 처리됩니다. 별도 서버 저장소, DB, 로그 저장 기능이 없습니다.

운영 시 권장사항:

- 주민번호, 계좌번호, 연락처 등 민감정보 제거 안내
- 파일 크기 제한 안내
- 외부 AI API 연동 전 개인정보 비식별화
- 서버 API 추가 시 Cloudflare Turnstile 및 rate limit 적용
- 업로드 파일 저장 금지 원칙 유지

## 한계와 개선 예정

PDF는 문서 구조에 따라 텍스트 추출 순서가 달라질 수 있습니다. 정확도를 높이려면 기관별 예산서 양식에 맞춘 항목 매핑표를 계속 보강해야 합니다.

추천 개선:

- 항목 매핑표를 JSON으로 분리
- 예산 목/세목/산출내역 구조화 파서 추가
- 산출기초 `단가 × 인원 × 월수` 자동 검산 강화
- 엑셀의 실제 시트명별 전용 파서 추가
- 검토 리포트 PDF 출력
- Cloudflare Worker 기반 서버 검증 옵션 추가
