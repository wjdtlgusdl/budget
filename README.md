# 예산서 검토 웹앱 v25

v24를 기준으로 다음 규칙을 추가했습니다.

- 교원급여, 교원수당, 직원급여, 직원수당 모두에 대해 금액 차액이 다른 `목`에 편성되었는지 추적합니다.
- PDF 개별 항목이 없을 때 엑셀 미개별 수당 합계를 계산하여 `교원수당/직원수당` 통합편성 여부를 판단합니다.
- PDF 천원 단위 편성을 고려해 ±1,000원 이내 차이는 반올림/절사 범위로 인정합니다.
- `식대 ↔ 정액급식비` 동의어는 교원수당/직원수당 목 안에서만 적용합니다.
- 법정부담금은 계속 검토 제외합니다.
