# Budget Review App v28

v27 결과표를 유지하면서 PDF 인원 중복 계산, 수당 개별편성 오인식, 통합편성 판정, 급여 차액의 다른 목 편성 추적을 보정한 버전입니다.

## 주요 변경
- 급여는 세부 직종별 행을 만들지 않고 `교원급여`, `직원급여` 총액/총인원 중심으로 검토합니다.
- 같은 산출항목이 보조금/수익자부담금으로 나뉜 경우 인원을 중복 합산하지 않습니다.
- 방과후교원급여는 교원급여와 별도 인력군으로 합산합니다.
- 수당 개별편성은 해당 `목(교원수당/직원수당)` 안의 명확한 항목만 인정합니다.
- `기타수당`이 `기타공공요금및제세공과금` 등으로 잘못 매칭되는 문제를 방지했습니다.
- 미개별표시 수당 합계가 PDF 교원수당/직원수당의 재원별 금액과 ±1,000원 이내로 맞으면 통합편성으로 표시합니다.
- 직원급여 등 급여 차액이 다른 목에 편성된 경우 검토결과와 지적사항에 표시합니다.


## v29 변경사항
- PDF 산출항목명이 산출기초 위/아래에 섞여 추출되는 경우 보정
- 직원방학휴가비 등 수당 개별편성 금액 오인식 보정
- 통합편성 추정 시 개별편성된 수당을 제외한 잔여 수당 합계만 비교
- 직원급여 차액의 다른 목 편성 탐지 정확도 개선


## v30 변경사항
- 직원수당 통합편성 추정 시 이미 개별편성된 수당 금액을 제외한 잔액만 비교합니다.
- PDF에서 첫 글자가 누락된 `량기사급여`를 `차량기사급여`로 보정합니다.
- 지적사항 표에는 퇴직적립금 관련 사항만 표시하고, 차액/다른 목 편성 내용은 검토결과 열에 표시합니다.


## v31
- 보수 시트 후보 점수 계산에서 과년도/부채 시트 오선택 방지
- 교직원보수일람표(년) 우선 유지
- 직명/본봉/지급액계 헤더를 행 기준 + 열 기준으로 이중 탐색
- 해아뜰/경기지혜숲 형식처럼 보수표 헤더가 다중행인 파일 인식 강화


## v32
- 보수 시트 헤더 탐색을 셀 단위/열 단위 이중 탐색으로 강화했습니다.
- XML 행 파싱에서 브라우저 호환성을 높였습니다.
