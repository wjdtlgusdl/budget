# 예산서 검토 정적 웹앱

교직원 보수기준 엑셀 파일과 세출예산명세서 PDF 파일을 브라우저에서 비교 검토하는 정적 웹앱입니다.

## 주요 기능

- 엑셀 교직원보수기준 시트 자동 탐색
- PDF 세출예산명세서 산출기초 자동 추출
- PDF 천원 단위 금액과 엑셀 원 단위 금액 비교
- 교원급여 인원수 비교
- 방과후교원급여, 직원급여 등 주요 인건비 비교
- 수당 개별 편성 확인
- PDF에 없는 수당 합계를 교원수당/직원수당 통합편성으로 판단
- 퇴직금 관련 시트에 적립금액이 있을 경우 PDF 편성 여부 확인
- 인건비성 항목이 급식비, 통학차량비 등 비인건비 과목에 편성된 경우 오편성 의심 표시

## GitHub 업로드 방법

1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다.
2. Cloudflare Pages에서 해당 GitHub 저장소를 연결합니다.
3. Framework preset은 `None` 또는 `Static HTML`로 선택합니다.
4. Build command는 비워둡니다.
5. Build output directory는 `/` 또는 비워둡니다.

## 사용 방법

1. 웹페이지에서 엑셀 파일을 업로드합니다.
2. 세출예산명세서 PDF 파일을 업로드합니다.
3. `검토 시작`을 누릅니다.
4. 결과 표에서 정상, 통합편성, 추가확인, 지적 항목을 확인합니다.

## 주의사항

- 모든 처리는 브라우저 내부에서 이루어집니다.
- 파일은 서버로 전송되지 않습니다.
- 엑셀 양식이 기관마다 다를 수 있으므로 실제 배포 전 예시 파일 여러 개로 검증해야 합니다.
- 자동 판정 결과는 최종 회계 검토를 대체하지 않으며, 보조 검토 도구로 사용해야 합니다.

## 커스터마이징 위치

`app.js` 상단의 `RULES` 객체에서 다음 항목을 수정할 수 있습니다.

- 보수 시트 탐색 키워드
- 퇴직금 시트 탐색 키워드
- 교원/직원/방과후 인원 분류 키워드
- 수당 헤더 키워드
- PDF 예산 항목 별칭
- 인건비 오편성 탐지 키워드

## 2026-05-14 수정 사항

- `9 교직원보수일람표` 시트를 우선 인식하도록 수정했습니다.
- `소계`, `합계` 행을 사람으로 중복 집계하지 않도록 수정했습니다.
- PDF에서 예산 과목 총액 행과 산출기초 행을 분리해 인식하도록 수정했습니다.
- 산출기초 금액 줄 뒤에 항목명이 나오는 PDF 구조를 처리하도록 개선했습니다.
- 교원급여 인원은 같은 항목의 여러 재원 산출기초를 합산하지 않고 최대 인원으로 판단합니다.


## v3 변경사항

- 법정부담금 관련 항목은 검토 대상에서 제외합니다.
- 제외 키워드: 법정부담금, 4대보험, 사학연금, 국민연금, 건강보험, 고용보험, 산재보험, 장기요양, 보험료
- 금액 비교, 인원 비교, 수당 통합편성, 오편성 탐지에서 모두 제외됩니다.

## v4 변경사항

- 엑셀 `9 교직원보수일람표`의 실제 열 구조를 기준으로 금액 추출 방식을 보강했습니다.
- 보수 행은 숫자 일련번호가 있는 실제 교직원 행만 집계하고, `소계`/`합계` 행은 제외합니다.
- 오편성 지적은 구체적인 항목명과 금액, PDF 위치가 확인될 때만 표시합니다.
  - 예: `차량기사급여 18,000,000원을 통학차량이용비에 편성`
- `수당`, `인건비성 항목`처럼 모호한 표현만으로는 지적하지 않습니다.
- 퇴직적립금 편성 여부는 결과표에 항상 표시합니다.
- 법정부담금, 4대보험, 사학연금, 사회보험 등은 계속 검토 제외합니다.

## v5 변경사항

- 사용자가 지정한 엑셀 범위 규칙을 반영했습니다.
  - `직명` 헤더 아래부터 `소계(교원)` 전까지를 교원 구간으로 인식합니다.
  - `소계(교원)` 아래부터 `소계(직원)` 또는 `소계(일반직)` 전까지를 직원 구간으로 인식합니다.
  - `본봉` 또는 `기본급` 열을 본봉열로 인식합니다.
  - 본봉열 바로 다음 열부터 `지급액계` 바로 전 열까지를 수당열로 인식합니다.
- 보수일람표의 개별 직명/성명 수식이 깨지는 경우에도 `소계(교원)`, `소계(직원/일반직)` 행의 금액을 우선 사용합니다.
- `월급여` 또는 `급여대장` 시트가 있으면 직명과 인원 판정을 보완합니다.
  - 방과후교사 구분은 월급여 시트의 직명에 `방과후`가 있는 경우 자동 보완합니다.
- PDF에서 같은 산출항목이 재원별로 반복될 경우 인원수는 중복 합산하지 않고 같은 항목의 최대 인원을 사용합니다.
